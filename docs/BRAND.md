# PE Admin brand (as used in the 2026 rebuild)

Source: pe-admin.de Elementor kit (`post-6.css`), logo PNGs, October 2026.

| Token | Value | Use |
| --- | --- | --- |
| `--pe-navy` | `#042D44` | kit secondary: dark sections, hero base |
| `--pe-night` | `#021B2A` | derived: deepest hero/footer tone |
| `--pe-blue` | `#1B6EA8` | kit primary: buttons, links, logo bars |
| `--pe-sky` | `#49B5F2` | logo light blue |
| `--pe-ice` | `#84D1FC` | light accent on navy |
| `--pe-ink` | `#0F121D` | kit text |
| `--pe-paper` | `#F8FBFF` | kit light background |
| `--pe-amber` | `#FFBC7D` | kit colour = warm sparks of the old hero photos |

- Font: **DM Sans** (kit), 400 text, 500 UI, 600/700 headings. Self-hosted.
- Radius 12 px (kit). Signature: the logo's E-bars, rounded top-right + bottom-left ("leaf" corners).
- Logo: vectorised from `PE_Admin-06.png` into three paths (dark / blue / light blue); dark = currentColor.
- Imagery: no stock photos. Light particles (amber + cyan sparks, blue-grey bokeh, warm flare), animated
  puzzle and flowchart scenes, founder portrait (Franz Swidriw) kept.
